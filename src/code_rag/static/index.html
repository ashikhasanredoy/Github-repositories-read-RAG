GitHub Code RAG — User Guide & Architecture

How the intelligent codebase analysis engine works

1 End-to-End Architecture & Workflow

AST Code Parsing

Parses codebases into Abstract Syntax Tree symbols (functions, classes, modules) preserving docstrings, parameters, and hierarchical dependencies rather than blind line slicing.

Hybrid Search (Dense + Sparse)

Combines ChromaDB vector embeddings (dense semantic search) with BM25Plus (sparse lexical search), fused via Reciprocal Rank Fusion (RRF) for high accuracy.

LangGraph Agent Routing

A state-machine agent classifies user intent into Full File Retrieval, Line-by-Line Code Explanation, Repository Architecture Tree, or Codebase Q&A.

Local LLM (Ollama) & SSE

Streams answers in real-time with Server-Sent Events (SSE), complete with execution traces, latency metrics, and cited code sources.

2 Core Features & Prompt Guidelines

Complete Source Code Retrieval:

Ask "Give me main.py" or "Show full file retriever.py". Returns original code with one-click Copy and Download buttons without unrequested explanations.

On-Demand Line-by-Line Code Explanation:

Ask "Explain main.py line by line" or "Explain lines 50-100 of graph.py". Provides sequentially numbered lines, syntax breakdown, purpose, variable roles, and project context.

Repository & File Structure:

Ask "Show repository structure", "file structure", or "explain project architecture" to see the codebase directory tree in a clean GitHub format.

Persistent SQLite3 Chat History:

Conversations and turns are permanently stored in data/chat_history.db. Deleting a question automatically deletes its AI answer via cascading turn deletion.
